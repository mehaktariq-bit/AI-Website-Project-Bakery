# AI-Website-Project-Bakery
Sweet Crumbs Bakery is a bakery website created as part of assignment 1.It presents bakery products such as cakes,cupcakes,with their pics
Lovable AI Tool is used for creating this website which includes bakery name & homepage,product prices, color theme and attractive website layouts.
Prompt Used:Create a bakery website named Sweet Crumbs Bakery with cakes,cupcakes,prices and pink and cream theme.
Live Link : https://bakery-sweet-crumbs.lovable.app/
